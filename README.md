# 📋 Анкета организации (PHP + JSON)

Система сбора заявок-анкет от организаций. Две версии:

- **`anketa/`** — классическая веб-форма на PHP (для обычного сайта)
- **`mini-app/`** — версия для **MAX Mini App** (аналог Telegram WebApp)

Форма сохраняет данные в JSON-файл и отправляет уведомление на почту администратора.

## ✨ Возможности

- 📝 **Форма анкеты** — организация, адрес, ИНН, контакт, телефон, email, вопросы, согласие
- 💾 **Сохранение в JSON** — все заявки хранятся в `responses.json`
- 📧 **Email-уведомления** — новая заявка приходит на почту админа
- 🔒 **Валидация** — проверка обязательных полей
- 📱 **MAX Mini App** — интеграция с SDK платформы MAX (нативные кнопки)

## 📁 Структура

```
anketa-max/
├── anketa/              # Веб-версия (PHP)
│   ├── index.php        # Форма
│   ├── submit.php       # Обработчик (JSON + email)
│   ├── admin.php        # Просмотр заявок
│   └── style.css
├── mini-app/            # Версия для MAX Mini App
│   ├── index.html       # Форма (MAX Web App SDK)
│   ├── app.js           # Логика
│   ├── submit.php       # Обработчик (JSON + email)
│   └── style.css
└── README.md
```

## 🚀 Установка

Требуется веб-сервер с PHP 7+ (Apache/Nginx, OpenServer, и т.д.).

1. Скопируйте папку на сервер
2. В `submit.php` укажите свою почту в `$admin_email`
3. Откройте `index.php` в браузере
